# AvaliacaoNodeAPI

Crie uma API de Filmes, onde serão armazenados Título, Classificação indicativa, Descrição e Lançado, utilizando a arquitetura REST.
Siga o padrão de Arquitetura MVC que vimos em aula.
Utilize o CRUD corretamente, assim como métodos e status https adequados.
Realize também a separação adequada dos arquivos conforme.

Não esqueça de validar tudo corretamente e fazer as tratativas de erros.
somente o link do github no teams

Crie uma função que será responsável por modificar apenas o status de Lançado do filme, sem que interfira em outras funcionalidades do sistema.
Crie ou modifique uma função, para listar todos os filmes de uma Classificação Indicativa informada pelo usuário(Postman).

EX: Listar todos os filmes L, Listar todos os filmes 10, etc.

- iniciar o repositório npm init
- instalar as dependências npm i express
- criar scripts dev package.json
- estruturar pastas e arquivos
- escrever códigos
    - index ( ponto de entrada)
    - router (caminho)
    - controller (req / res)
    - service (manipulação dos dados)
    - model (banco/ onde processa)
